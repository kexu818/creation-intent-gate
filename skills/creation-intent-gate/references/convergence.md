## 使用原则

- 评分帮助显化判断，不替代人的 Values。
- AI 只能基于可查证 Context 提议自洽分；没有用户证据时明确标记“待用户校准”。
- 他洽优先使用访谈、行为、付款、真实配合、旧流程和一手市场资料；不能只靠创作者想象。
- 评分相同不代表路径相同；同时保留代价、最大未知和证据强度。

## 自洽维度

按创造物调整权重，默认检查：

1. 兴趣与吸引力：用户是否真的想长期靠近这个状态。
2. 能量结构：它是持续补充能量，还是依赖长期意志力和厌恶性工作。
3. 能力与不对称优势：现有经历、Context、关系和能力是否形成优势。
4. 身份与长期方向：成功后是否成为用户愿意成为的人。
5. 掌控感：是否保留关键事实源、判断权、迁移权和退出权。
6. 复利资产：是否沉淀数据、方法、规则、案例、品牌、关系或可复用能力。
7. 边界代价：是否需要牺牲隐私、健康、声誉、自由或不愿承担的责任。

## 他洽维度

按目标对象调整权重，默认检查：

1. 痛点强度与紧迫性。
2. 新体验相对旧体验的改善幅度。
3. 替换成本：学习、迁移、信任、数据、组织和心理成本。
4. 使用、配合或付费意愿。
5. 获取用户或进入真实场景的可达性。
6. 价值是否可验证、可解释、可持续。
7. 市场与竞品证据：是否已有相邻需求和替代方案。

## 评分锚点

使用 1-5 分，可保留 0.5：

- `1`：明显冲突或已有反证。
- `2`：弱成立，关键条件大多缺失。
- `3`：有可能，证据不足或代价较高。
- `4`：较强成立，有实际 Context 或外部证据。
- `5`：高度成立，已有持续行为、真实使用、付款/配合或不可忽视的优势。

为每个总分附 `evidence_strength`：`weak`、`medium`、`strong`。不要用小数制造虚假精确。

## 收敛规则

默认保留四类判断：

- `keep`：双高，作为主 Vision 或优先现实碰撞。
- `skeleton`：自洽高、他洽不足；保留为骨架，通过更小实验验证需求和替换成本。
- `rebuild`：他洽高、自洽不足；改变角色、交付方式、责任边界或商业关系后再评估。
- `fold`：双低；暂停或折叠进其他路径，不继续独立投入。

最终输出：

1. 一个主 Vision。
2. 一个备选 Vision。
3. 明确暂停/放弃项及理由。
4. 主 Vision 的最大未知与最小验证动作。
5. 用户亲自确认的 Values 选择规则。

## 可视化输入

`scripts/render_convergence_map.py` 接受以下 JSON：

```json
{
  "title": "创造物自洽 × 他洽收敛",
  "threshold": 3.0,
  "items": [
    {
      "id": "A",
      "name": "路径名称",
      "self_score": 4.5,
      "other_score": 4.0,
      "decision": "keep",
      "note": "最关键判断"
    }
  ]
}
```

横轴固定为他洽，纵轴固定为自洽。图中注明“坐标为分析判断，不是客观评分”。生成后必须实际查看，必要时调整标签或画布。
